# User Stories — Chicaffe

## EP-01 Authentication

### US-01

**As an administrator, I want to register users with name, email, and password, so that I can grant access to the system.**

### US-02

**As a system, I want to validate that emails are unique, so that duplicate accounts are avoided.**

### US-03

**As a user, I want to see validation messages when fields are empty, so that I can correct my input.**

### US-04

**As a user, I want to log in with my credentials, so that I can access the system.**

### US-05

**As a user, I want to be redirected to the dashboard after login, so that I can start working immediately.**

### US-06

**As a user, I want to log out at any time, so that I can protect my account.**

### US-07

**As a system, I want to restrict access to protected routes, so that security is enforced.**

---

## EP-02 User Management

### US-08

**As an administrator, I want to view all users, so that I can manage them.**

### US-09

**As an administrator, I want to search users by name, so that I can find them easily.**

---

## EP-03 Products & Inventory

### US-10

**As an administrator, I want to create, update, and delete products, so that I can keep the menu updated.**

### US-11

**As a system, I want to register inventory movements (SALE / RESTOCK), so that stock is controlled.**

### US-12

**As a user, I want to see when a product is out of stock, so that I avoid selecting it.**

### US-13

**As a system, I want to prevent adding products to orders if stock is insufficient, so that errors are avoided.**

---

## EP-04 Tables

### US-14

**As an administrator, I want to manage tables (number and capacity), so that service is organized.**

---

## EP-05 Orders

### US-15

**As a user, I want to create orders linked to a user and table, so that sales are recorded.**

### US-16

**As a user, I want to add products to an order, so that I can record consumption.**

### US-17

**As a system, I want to manage the lifecycle of an order, so that its status is accurate.**

### US-18

**As a system, I want to decrease inventory when products are added to an order, so that stock remains updated.**

### US-19

**As a system, I want to restore inventory when an order is cancelled, so that stock is corrected.**

### US-20

**As a system, I want to prevent invalid order status transitions, so that consistency is maintained.**

---

## EP-06 Reports

### US-21

**As an administrator, I want to generate daily sales reports, so that I can analyze business performance.**
